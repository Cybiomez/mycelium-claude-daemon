# Журнал решений

## 30-09-2026 — доработки под Telegram-клиент (v0.2.0)

- **Один живой ход на весь демон** (`maxConcurrent: 1`). Процесс Claude — 300–450 МБ, бокс — 2 ГБ, рядом живут процессы VS Code. Касается всех клиентов, включая Pocket (согласовано). При росте памяти — поднять в `config.json`.
- **Сторож памяти по `MemAvailable`**, а не по числу своих процессов: демон не видит процессы VS Code, а память они едят. Перед ожиданием закрываем свои простаивающие процессы.
- **Очередь по кругу между сессиями**: иначе пачка сообщений в одной теме задерживает все остальные.
- **Смена настроек = перезапуск процесса.** У SDK есть `setModel()`, но effort живьём не меняется; один путь для всех настроек проще и предсказуемее. Цена — холодный старт следующего хода.
- **Памятка канала — на ход, а не на процесс** (`appendSystemPrompt`). В одной сессии (TGChat) подряд идут ходы из разных мест с разными ограничениями. Памятка пишется в транскрипт блоком `<channel-context>`; история её вырезает. Осознанное упрощение: в VS Code при открытии такой сессии памятка видна как текст пользователя.
- **Проверка занятости сессии по `/proc`**: ищем процессы с `--resume <id>`, исключая потомков демона. Только Linux; на другой ОС вернёт «свободна».
- **Список моделей — у самого Claude Code** (`supportedModels()`), не в коде: новые модели появляются в меню клиентов без правок.

## 08-11-2026 — архив сессий в движке
Удаление сессии — полное: транскрипт, папка файлов и чек-лист уходят из
`~/.claude/projects/...` в `~/archive/sessions/` (вне рабочего пространства и вне
ночного бэкапа), через 90 дней — безвозвратно. Архив живёт в движке, потому что
сессии — его зона: клиенты (бот, ClaudePocket) только вызывают API и файлы не трогают.
Список сессий строится по транскриптам, поэтому перенос транскрипта сам убирает
сессию из списка — отдельный «чёрный список» не нужен. Упрощение: занятость
сессией в VS Code определяется по `locks.mjs`; если сессия открыта во вкладке без
живого процесса, перенос пройдёт, а VS Code при следующем ходе создаст пустой
транскрипт заново — такую вкладку надо закрыть.
